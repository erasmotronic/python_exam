<h1>History</h1>
<p>Back in 2023, I enrolled in a Python course for data analysis. This project represents what I learned back then. In specific, I was taught how to use the Pandas library for data exploration and manipulation. Since then, these skills enabled to handle data much more efficiently than just relying on Excel functions. In fact, previous reports that were built entirely in Excel can now be built with Pandas library, but presented still as an Excel spreadsheet report. Long reports could now run in a single script in a matter of seconds.</p>
<p>Sunce then, a lot of things have changed. Consequently, I was forced to expand on my knowledge. Firstly, during this course I was taught to use the Spyder and Jupyter IDEs. Likewise, both were built-in in the Anaconda suite, which creates a custom environment with necessary dependencies. Nonetheless, I was never exposed in how to work Python in a development environment. Secondly, because I was using Anaconda for work now, the licensing scenario was different than I when I was student. Meaning, I need to use my Pandas skills but in a different IDE. Finally, I had to start learning Python from the basics on my own. In other words, I learned how to use Pandas, but the curriculum neglected or ignored how to work properly with a Python environment. Specifically, the curriculum did not teach data analysts how to use Python in a development IDE.</p>
<p>In retrospect, I feel like a noob relying originally in Anaconda. Honestly, I feel it now like a crutch. Still, I think this is a great IDE designed for data analysis. Yet, I find liberating to be to use any IDE to set up dependencies and environments properly. In a simplistic manner, this is like learning to write with a specific brand pen, but then forced to use any pencil. Yes, it now involves sharpening and getting gum erasers, but would you say to a client or co worker, "I do not know how to write with pencil, I can only write with this brand of pen"?</p>
<p>I took that final project and modified it a bit. I worked in VS Codium, and created a requirements file in case you want to reproduce it yourself (pip install -r requirements.txt). Used data is open-sourced.</p>
